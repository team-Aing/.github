## About

Aing은 인공지능을 주전공으로 하는 학생들의 전공동아리입니다.

각자의 프로젝트를 이곳에 공유하고, 서로의 작업에 피드백을 더하며 아이디어를 함께 발전시킵니다.
동아리 단위의 서비스 개발 또한 이곳에서 함께 진행합니다.
